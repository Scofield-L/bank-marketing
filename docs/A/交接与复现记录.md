## B 的使用接口

在 `code/03_modeling.py` 中可直接使用：

```python
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV, StratifiedKFold
from bank_preprocessing import ROOT, make_model_pipeline

train = pd.read_csv(ROOT / 'data/processed/train.csv', index_col='sample_id')
test = pd.read_csv(ROOT / 'data/processed/test.csv', index_col='sample_id')
X, y = train.drop(columns='y'), train.y
pipeline = make_model_pipeline(LogisticRegression(max_iter=1000), strategy='none')
search = GridSearchCV(pipeline, {'model__C': [0.1, 1, 10]}, scoring='roc_auc',
                      cv=StratifiedKFold(5, shuffle=True, random_state=42))
search.fit(X, y)
# 只在训练集完成选择后评估测试集，保持 test 原始行顺序。
prediction = pd.DataFrame({
    'sample_id': test.index,
    'y_true': test.y.to_numpy(),
    'y_pred': search.predict(test.drop(columns='y')),
    'y_probability': search.predict_proba(test.drop(columns='y'))[:, 1],
})
```

`strategy` 支持 none/class_weight/undersample/smote。smote 使用 SMOTENC；不支持 class_weight 的模型会明确报错。B 应记录模型参数、数据校验值、种子、特征口径和采样策略。
