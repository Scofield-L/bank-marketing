# A 数据说明

核验日期：2026-11-10。当前工程默认采用 `bank-full.csv`，尚待 B/C 确认。

## 来源与版本

- 官方主页：https://archive.ics.uci.edu/dataset/222/bank+marketing
- 下载地址：https://archive.ics.uci.edu/ml/machine-learning-databases/00222/bank.zip
- 对照说明：压缩包中的 `bank-names.txt`，保留于 `data/`。
- 下载日期：2026-11-10；原始数据未经覆盖或修改。
- SHA256：`d1513ec63b385506f7cfce9f2c5caa9fe99e7ba4e8c3fa264b3aaf0f849ed32d`。
- 实测 45,211 行、17 列，即 16 个输入字段和目标 y；分隔符为分号。
- `bank.csv` 仅 4,521 行，不满足课程至少 5,000 条要求。
- `bank-additional-full.csv` 为另一版本：41,188 行、20 个输入字段，`pdays=999` 表示未联系。本工程明确拒绝该 schema，避免版本混用。
- UCI 网页部分文字的字段数有歧义；以 CSV 表头和随包 `bank-names.txt` 的 16 + 1 为准。

## 数据质量实测

整行重复 0 条，所有字段真正空值均为 0。未删除样本。`unknown` 为数据中的显式类别，不能当作空字符串。

| 字段 | unknown 条数 |
|---|---:|
| job | 288 |
| education | 1857 |
| contact | 13020 |
| poutcome | 36959 |

其余类别字段 unknown 均为 0。`pdays=-1` 共 36,954 条。类别全集与数值四分位数见运行生成的 `data/processed/manifest.json`。

目标 no=39,922，yes=5,289，正类占 11.6985%。极端年龄、余额、联系次数在缺少错误证据时保留，不依据测试集裁剪。无客户唯一标识，无法验证同一客户跨行出现；行号不是客户 ID。

默认采用最后一次通话发生前、联系安排已知的预测假设，因此排除 duration；campaign 包括当次联系，实际部署前仍需确认该计数及 day/month 的可用时点。随机划分不是未来时间外推验证，后续应由 B/C 评估时序划分需求。
