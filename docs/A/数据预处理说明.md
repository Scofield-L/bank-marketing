# A 数据预处理说明

## 默认方案

1. 严格验证 bank-full 表头、样本规模、标签与数值范围，不静默切换数据版本；保留原始行索引为 `sample_id`。
2. 先按 y 分层划分 80%/20%，随机种子 42。此后只在训练集拟合；交叉验证时通过 Pipeline 在每个训练折重新拟合。
3. y 映射为 no=0、yes=1。默认排除 duration；通话后对照实验使用 `--include-duration` 并指定独立输出目录。
4. 保留 unknown 类别；真正数值缺失按训练集各列中位数填补，真正类别缺失填为 `missing`。当前原始数据无真正缺失，规则用于后续输入兼容。
5. 数值使用 StandardScaler；树模型可用 `scale=False`。负余额、合法长尾值不删除或截尾。pdays=-1 作为业务哨兵保留，未擅自解释为缺失或改成 999；其派生特征等待 B 的 EDA。
6. 无序类别 One-Hot，不人为添加序数关系。未知新类别在转换时以该字段全零向量处理。类别全集仅从当前训练数据学习。
7. 默认保持原始类别分布。可选 class_weight=balanced、随机欠采样和 SMOTENC。SMOTENC 先填补/缩放数值，再对混合类型采样，最后 One-Hot，避免对独热类别直接插值。SMOTE 合成后的计数可为小数，是实验方案的局限；极小训练折若少数类不足默认近邻数会报错，应由 B 调整方案。

## 处理前后实测

| 项目 | 结果 |
|---|---:|
| 原始样本 | 45211 |
| 删除样本 | 0 |
| 默认原始输入字段 | 15（排除 duration） |
| 训练集 / 正类 | 36168 / 4231 |
| 测试集 / 正类 | 9043 / 1058 |
| 编码后训练矩阵 | 36168 × 50 |
| 编码后测试矩阵 | 9043 × 50 |

测试集不参与采样，保留原始分布。50 列为该固定划分下的结果，其他训练折类别缺失可能改变列数。

## 输出与防泄漏

`train.csv`、`test.csv` 包含 sample_id、未拟合处理的输入列和二进制 y，供 B 建模。`matrices.npz` 和 `preprocessor.joblib` 是完整训练集拟合后的便捷产物，只用于固定训练/测试实验，不可用于交叉验证调参。调参必须将原始训练表传给 `make_model_pipeline`。特征名顺序见 manifest，与矩阵列严格对应。

统计报告包含全量数据描述，仅用于质量核对；不能据测试数据统计选择特征或调参。不要加载来源不可信的 joblib 文件。
