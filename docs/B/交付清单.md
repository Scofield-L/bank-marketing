## C 的读取入口

从 `data/modeling/manifest.json` 的 `recommended` 读取推荐实验名，用 `cv_summary.csv` 的 `experiment` 和 `predictions` 列定位该实验的预测表。测试预测按 `sample_id` 与 A 的 `test.csv` 核对，`y_probability` 对应订阅正类 1。主实验筛选 `include_duration=False`，通话后对照为 `duration_control`。若需调阈值，先用训练集的 `recommended_oof.csv` 选定阈值，再在测试集计算指标。
