# B 的实验复现与评估交接

项目根目录的 `requirements.txt` 统一管理 A 的预处理依赖及 B 使用的 Matplotlib、XGBoost。已有 A 的 `data/bank-full.csv` 和 `data/processed/` 时，在项目根目录使用运行 A 脚本的 Python 3.12 环境执行以下命令。

```powershell
python -m pip install -r requirements.txt
python code/02_eda.py
python code/03_modeling.py --jobs 4
```

`--jobs` 控制交叉验证的并行进程数，默认 1。两个脚本均可通过 `--processed` 指定 A 的通话前数据目录、通过 `--raw` 指定与 manifest 校验值一致的原始 CSV。

## 实验口径

- 复用 A 的分层 80/20、seed 42 划分。训练集 36,168 条、测试集 9,043 条，订阅为正类 1。所有选型使用同一组训练集分层五折，按平均 AP 排序，AP 相同则比较 ROC AUC。
- 主实验使用 A 的 15 个通话前字段。暂按对某一次即将拨出的电话评分，假设计划日期（`day`、`month`）、联系渠道 `contact` 和本次尝试序号 `campaign` 可用。原始字段描述对应记录中的最后一次联系，`campaign` 包含该次联系。若实际要在排期之前圈选客户，或无法在拨出前构造这些字段，需要调整特征并重新验证。随机划分的结果对应同一数据集上的留出评估。
- 对 LR、DT、RF、XGBoost 分别比较原始分布、类别加权、随机欠采样和 SMOTENC。XGBoost 使用当前训练折标签计算样本权重，其余模型使用 `class_weight='balanced'`。LR 和 SMOTENC 距离计算用到的数值特征做标准化。填补、编码、缩放和采样均使用 A 的 Pipeline 在训练折拟合。
- 先对初选赢家比较两种 `pdays=-1` 表示，分别为保留原值、转成缺失后由训练折的已联系样本中位数填补。两者都保留 `previous`。随后在所选口径上用小网格调参，候选含原配置。含 `duration` 的对照沿用通话前推荐方案的参数和划分。
- CV 表中的 AP 指 Average Precision。若 C 另算梯形积分的 PR-AUC，报告中应分别标注。默认预测标签使用 `y_probability >= 0.5`。加权或采样所得分数可用于排序和阈值分析，若需解释为实际订阅概率，应另做校准检查。

## 交给 C 的文件

| 产物 | 用途 |
|---|---|
| `figures/eda/*.png`、`data/eda/*.csv` | 训练集的 EDA 图与原始统计 |
| `data/modeling/manifest.json` | 推荐实验名、对照实验名、数据和划分 SHA256、环境版本 |
| `data/modeling/cv_summary.csv` | 每个实验的五折均值、标准差和相对产物路径 |
| `data/modeling/cv_candidates.csv` | 各候选参数及逐折分数 |
| `data/modeling/predictions/*.csv` | 每个实验的测试集预测。列为 `sample_id,y_true,y_pred,y_probability`，行序与 A 的 `test.csv` 一致 |
| `data/modeling/recommended_oof.csv` | 推荐方案在训练集上的折外预测，与 A 的 `train.csv` 行序一致 |
| `data/modeling/importance/*.csv` | 编码后特征的 LR 系数、DT/RF 不纯度重要性或 XGBoost gain |
| `data/modeling/models/*.joblib` | 在全训练集上拟合的 Pipeline。加载时使用同版依赖，并将项目的 `code/` 加到 Python 模块搜索路径 |

读取 `cv_summary.csv` 可定位各模型的预测文件。按 `sample_id` 与 A 的测试表核对样本和标签，主实验对比筛选 `include_duration=False`。如需选阈值，可先用 `recommended_oof.csv`，固定阈值后再在测试集评估。折外概率逐行来自未见过该行的模型，但超参数已用同一训练集选过，正式结果仍以独立的留出测试集为准。

EDA 统计、建模结果表和实验清单随代码交付。模型文件可通过组内共享目录获取，或运行上述命令重训。详见 [B 的交付清单](交付清单.md)。

## 报告草稿

### 探索性分析

训练集包含 4,231 条订阅和 31,937 条未订阅记录，订阅率为 11.70%。按历史联系记录分组，`pdays=-1` 的 29,584 条记录订阅率为 9.22%，`pdays` 在 31–90 天的 439 条记录中为 41.69%。这些分组的样本量相差较大，相关性热图中的 `pdays` 系数仅在有历史联系天数的记录上计算。当前营销活动仅联系 1 次的记录订阅率为 14.59%（14,026 条），超过 8 次的记录为 4.74%（1,413 条）。以上是样本中的关联，分组还可能受到客户筛选和营销策略的影响。

通话时长 0–60 秒组订阅率约 0.16%（3,820 条），600 秒以上组为 48.60%（3,043 条）。通话时长只能在通话后获得，因此从主实验移除并单独做对照。

### 数据挖掘

以逻辑回归为基线，在相同的数据划分上比较四类模型和四种不平衡处理策略。选型和调参以训练集五折 AP 为准，同时记录 ROC AUC、准确率、精确率、召回率和 F1 的折间均值及标准差。确定模型之后，在全训练集重训并向评估阶段交付测试集预测及正类分数。

下表为固定初始参数的五折平均 AP。

| 模型 | 原始分布 | 类别加权 | 随机欠采样 | SMOTENC |
|---|---:|---:|---:|---:|
| 逻辑回归 | 0.4021 | 0.3985 | 0.3928 | 0.3782 |
| 决策树 | 0.1773 | 0.1765 | 0.1603 | 0.1697 |
| 随机森林 | 0.4115 | 0.4112 | 0.3993 | 0.3732 |
| XGBoost | 0.4219 | 0.4147 | 0.4052 | 0.4079 |

初选赢家是原始分布下的 XGBoost。对同一模型，将 `pdays=-1` 转为缺失后，AP 由 0.4219 降到 0.4176，本次沿用原值。网格搜索选择 `max_depth=3`、`n_estimators=100`，五折 AP 为 0.4427（折间标准差 0.0110），ROC AUC 为 0.7968。推荐实验名为 `xgb_none_tuned`，留出测试集 AP 为 0.4604、ROC AUC 为 0.8038。加入 `duration` 的通话后对照在同一测试集上的 AP 为 0.6215、ROC AUC 为 0.9327。

本次在 Windows / Python 3.12.16 上运行。A 的 3 项回归测试及依赖检查通过。19 份测试预测表的样本 ID 和标签均与 A 的测试表一致，序列化模型重新加载后可复现正类分数。
